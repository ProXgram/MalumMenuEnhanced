Extract this archive to inspect or modify the library. Follow its README,
project files and upstream build workflow for the .NET SDK and NuGet package
restore/build requirements. The source archive has no Git submodules.
External package dependencies are pinned in the supplied project/build files;
the build tools and package dependencies can be restored from their upstream
locations. No independently reproduced binary build is claimed here.

The libraries remain separate DLLs under BepInEx/core. With the game closed,
users may replace them with interface-compatible modified versions. Preserve
the originals for restoration if needed. The distributed component hashes
identify the supplied originals; they impose no runtime lock against modified
libraries. This distribution adds no restriction on modification or reverse
engineering for debugging modifications to these libraries.

When redistributing these library binaries, retain their notices, complete

is not the corresponding-source material provided by this package. If the

under the applicable license. LGPL section 4 describes the additional
